未下载模型。正式运行 622.937 秒，110 个物理请求；另外接口预检有 3 个请求，不计入下表。

## 协议与结果

自建任务共 24 项，含创建、重命名、追加、筛选、多步骤操作和必要澄清；中英文各半。
12 项用于开发校准，12 项为留出任务，五种策略各独立调用一次，共 60 项留出尝试。
实际声明式文件工具只在临时目录执行，由独立评分器检查完整文件终态和 UTF-8 字节。
规则、原型和逐类能力映射不依据留出成绩更新。这不是通用 Bash Agent 或公开 benchmark 的端到端成绩。

五组均有 12/12 完整留出证据。上述延迟包含路由、加载、求解、降级和工具/评分处理，
不等于纯推理延迟，也未测 TTFT。正式请求账为：开发校准 24 chat、原型建立 1 embedding、
留出 73 chat + 12 embedding，合计 110。规则组有一次输出契约失败导致换模型，未根据金标准触发降级。

## 结论的适用范围

开发集上两个模型均为 5/12；逐类成功率也相同。Qwen3 开发 compute 代理较低，
被冻结的六类映射全部选择 Qwen3。**三种路由的初始模型选择因此都退化为固定 Qwen3，
本轮不能证明智能选型提高了质量。**

Embedding 组相对固定 Qwen3 多成功一题（8.3 个百分点），配对差的描述性 bootstrap 95% 区间为
[0.0, 25.0] 个百分点，含零。求解请求字节哈希相同的 13 个重复组中，2 组的成功结果发生波动。
这些重复来自策略调用，而非事先独立安排的重复实验；一题差异不能归因为 Embedding 路由收益。
模型分类路由 p50 分类耗时约 1.375 秒，增加了请求；在本轮未得到成功率收益。

同 case/repeat 的两个固定对照完整，36 个路由尝试有完整误选诊断证据，未识别出初始模型误选。
这不代表不存在生产错路由：两者均失败不会记为错路由，12 个案例也不能覆盖真实业务任务分布。
API 费用为未知；Token、请求与 compute 是资源代理，没有测量费用、能耗或显存占用。
